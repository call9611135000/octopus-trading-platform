# Octopus — Modular Desktop Trading Platform

**Development preview · Python · Windows · Charting · Technical Analysis**

Octopus is a Python/Tkinter desktop charting application being developed into an independent, modular trading platform. Its roadmap includes installable extensions such as Magic Algo.

**Current status:** V082 is the latest user-confirmed stable chart baseline. The source is available under [`releases/Octopus_V082_Live_Candle_Recovery.pyw`](releases/Octopus_V082_Live_Candle_Recovery.pyw). The application remains a development preview: broker order execution is disabled, public market data may be delayed, and Windows runtime behavior requires local verification. Do not rely on it for live trading.

## Development priorities

- Reliable charts, drawings, indicators, and workspace management
- Save / Save All with backward-compatible workspace and historical-data persistence
- Consistent, precisely aligned menu icons (known issue in V060)
- A module manager for optional products, including Magic Algo
- Windows installation under Program Files, with user data stored separately
- Automated tests, accessibility, performance and broker integration safeguards

## Running the development version

The current development source is `Octopus_V060.pyw`, intended for Windows with Python and its required dependencies. The application source will be uploaded separately. Do not run with administrator privileges.
