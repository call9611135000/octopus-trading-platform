# Contributing to Octopus

Thank you for helping improve Octopus.

1. Open an issue describing a bug or feature before major changes.
2. Fork the repository and submit focused pull requests.
3. Preserve Save, Save All, workspace migrations, chart navigation, and data integrity.
4. Include reproduction steps, screenshots and tests for GUI changes.
5. Run a Python syntax check and describe Windows runtime test results.
6. Never commit broker credentials, access tokens, personal market data or user databases.
7. Respect third-party code and asset licenses.

**License and contribution policy are pending.** Maintainers will finalize these before accepting code contributions.
